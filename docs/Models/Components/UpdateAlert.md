# UpdateAlert

| ------------------------------------------- | ------------------------------------------- | ------------------------------------------- | ------------------------------------------- | ------------------------------------------- |
| `status`                                    | *string*                                    | :heavy_check_mark:                          | The alert's new status. Must be `resolved`. | resolved                                    |
